# Turn-Based Arena

A small game concept where two fighters take turns choosing an action.

## How to play

- Each fighter starts with ten health points.
- Attack deals two damage.
- Defend reduces the next incoming attack by one damage.
- Heal restores one health point, up to the starting maximum.
- The last fighter standing wins.

## First version

A player fights a computer opponent that chooses actions randomly. Show health bars and a short battle log.

## Optional Solana idea

A future devnet prototype could save match results. Combat can stay local, with no tokens or payments needed.
